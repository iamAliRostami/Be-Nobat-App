# بي نوبات

تتضمن الواجهة تجربة دخول محسّنة ومتوافقة مع لوحة المفاتيح واتجاه RTL، مع شعار BN وأيقونة تطبيق جديدة.

[فارسی](README.fa.md) · [English](README.md) · **العربية**

«بي نوبات» هو تطبيق Android لحجز المواعيد مطوّر بلغة Kotlin. يدعم الإصدار الحالي تسجيل الدخول
بالبريد الإلكتروني أو رقم هاتف إيراني من خلال PocketBase.

## الميزات الرئيسية

- فصل طبقات العرض والنطاق والمستودع ومصدر البيانات البعيد
- حقن الاعتماديات باستخدام Koin
- الاتصال بالشبكة باستخدام Ktor وKotlin Serialization
- تخزين رمز تسجيل الدخول بصورة آمنة
- دعم العربية والفارسية والإنجليزية مع اتجاه تلقائي من اليمين أو اليسار
- محدد لغة داخل شاشة تسجيل الدخول
- تسجيل آمن لطلبات API في نسخة Debug فقط

## واجهة API للتطوير

تتصل نسخة Debug بخادم PocketBase على `http://10.0.2.2:8090`. مسار المصادقة هو
`/api/collections/users/auth-with-password`. استبدل عنوان Release التجريبي في
`app/build.gradle.kts` بعنوان الخادم الحقيقي قبل النشر.

## البناء والاختبار

```bash
./gradlew test
./gradlew assembleUserDebug
```

يتطلب المشروع إصدار Gradle المحدد في `gradle/wrapper/gradle-wrapper.properties` وAndroid SDK
متوافقاً مع compile SDK الخاص بالمشروع.

## تغيير اللغة

افتح شاشة تسجيل الدخول واضغط زر اللغة في أعلى الشاشة، ثم اختر English أو فارسی أو العربية. يدير
AppCompat لغة التطبيق المختارة ويحافظ عليها عند إعادة إنشاء الأنشطة. تُختار الفارسية تلقائياً في
التشغيل الأول، ولا يستبدل التطبيق اختيار المستخدم بعد ذلك.
